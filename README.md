## English

ReadGmail is a small personal automation tool for Windows (C# / .NET Framework WinForms). It signs in to the developer's **own** Google account through Google OAuth 2.0 and uses the Gmail API to find a specific verification code in incoming emails, so that the code can be used by the developer's own automation.

### Key points

- **Personal use only.** This app is built for, and used by, its developer. It is not a public service and is not offered to other users.
- **Minimal access.** It uses the Gmail API (read-only access) to look for a verification code in emails of the signed-in account.
- **No sharing.** It does not sell, share, or transfer Gmail data to any third party.
- **Runs locally.** The app runs on the developer's own computer.

## 繁體中文

ReadGmail 是一個 Windows 個人自動化小工具（C# / .NET Framework WinForms）。它透過 Google OAuth 2.0 登入開發者**本人**的 Google 帳號，並使用 Gmail API 從收到的郵件中找出特定的驗證碼，供開發者自己的自動化流程使用。

### 重點

- **僅供個人使用。** 此應用程式由開發者為自己開發並使用，不是公開服務，也不提供給其他使用者。
- **最小權限。** 使用 Gmail API（唯讀權限），在已登入帳號的郵件中尋找驗證碼。
- **不分享資料。** 不會販售、分享或轉移 Gmail 資料給任何第三方。
- **本機執行。** 應用程式在開發者自己的電腦上執行。
